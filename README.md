# Luna Telegram

Mini App + bot Telegram untuk pelacakan siklus menstruasi & kesuburan,
dibangun di atas [Telegram Serverless](https://core.telegram.org/bots/serverless)
(`tgcloud`). Saudara terpisah dari `luna-kalender-siklus` (repo `html5-project`; versi
single-file HTML5 client-only) — bukan migrasi atau pengganti.

## Status

**Perencanaan — belum ada implementasi.** Lihat `PRD.md` untuk logika
produk lengkap (perhitungan fase siklus, deteksi ovulasi, analisis,
reminder, Mode Berbagi, dst). Lihat `CLAUDE.md` untuk konteks kerja,
termasuk kenapa proyek ini sengaja menyimpang dari konvensi "single-file,
tanpa build step" yang dipakai proyek lain di monorepo `html5-project`.

## Dokumentasi

- `PRD.md` — spesifikasi logika produk lengkap, mulai dari sini.
- `CLAUDE.md` — konteks & batas kerja untuk sesi AI di repo ini.
